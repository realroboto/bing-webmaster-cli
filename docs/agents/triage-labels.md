# Triage labels

Canonical triage roles → the label strings used in this repo's GitHub issues. All equal to their canonical name (GitHub defaults reused where present).

## Category roles

| Canonical | Label |
|---|---|
| bug | `bug` |
| enhancement | `enhancement` |

## State roles

| Canonical | Label |
|---|---|
| needs-triage | `needs-triage` |
| needs-info | `needs-info` |
| ready-for-agent | `ready-for-agent` |
| ready-for-human | `ready-for-human` |
| wontfix | `wontfix` |

Every triaged issue carries exactly one category role and one state role.
